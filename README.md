# 特教宣導互動網站

這是一個可直接部署到 GitHub Pages 的純前端靜態網站。

## 檔案
- `index.html`：特教宣導互動學習站
- `quiz.html`：隨機抽 10 題的特教宣導闖關測驗

## 使用方式
- 學生可自由瀏覽互動宣導內容，不強制完成全部學習區。
- 首頁上方可直接按「直接開始測驗」。
- 頁面最下方也可隨時進入測驗。
- 學習進度僅作為探索紀錄，不影響測驗資格。

## 測驗規則
- 題庫共 30 題
- 每次隨機抽 10 題
- 題目順序隨機
- 每題四個選項順序隨機
- 正確答案位置會隨機出現在 A/B/C/D
- 題目與每個選項都有獨立報讀按鈕
- 10/10 全對才闖關成功
- 共 2 次機會
- 第一次未全對時，可選擇「使用第 2 次機會」或「換下一位」
- 按「換下一位」會清除上一位作答狀態，下一位從第 1 次機會重新開始
- 第二次會重新抽 10 題

## GitHub Pages 部署
1. 建立一個新的 GitHub repository。
2. 將本資料夾內的所有檔案上傳到 repository 根目錄。
3. 進入 `Settings` → `Pages`。
4. 在 `Build and deployment` 中選擇 `Deploy from a branch`。
5. Branch 選 `main`，Folder 選 `/ (root)`。
6. 儲存後等待 GitHub Pages 建立網址。

本網站不依賴外部 CDN，可離線開啟。
